# Security policy

This prototype is a control-plane foundation, not a security boundary for untrusted arbitrary code. Review [THREAT-MODEL.md](THREAT-MODEL.md) before integrating it.

Do not open a public issue containing an undisclosed vulnerability, credential, customer record, private workflow, or provider token. Contact the repository maintainer privately through the security-reporting channel configured on the GitHub repository. If no private reporting channel is visible, open a public issue that contains only the words `Private security contact requested` and no technical details.

Reports should identify the affected version or commit, the protected property that fails, the smallest safe reproduction, and the likely impact. Receipt does not promise a response deadline or bounty.
