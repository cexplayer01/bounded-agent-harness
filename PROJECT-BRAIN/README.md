# Bounded Agent Harness project brain

This brain belongs only to the `bounded-agent-harness` project in this repository. It is not the USB, DFW Metro, FreeVibeApps, or game-project brain.

## Read for a BAH task

1. [`PROJECT.json`](PROJECT.json) — project identity and explicit cross-project pointers.
2. [`CURRENT-STATE.md`](CURRENT-STATE.md) — current BAH source and published-site facts.
3. [`NEXT-STEP.md`](NEXT-STEP.md) — the active BAH continuation unit.
4. [`TAKEOVER-CHECKPOINT.v1.json`](TAKEOVER-CHECKPOINT.v1.json) — machine-readable stop point; validate against this repository's branch and worktree.
5. [`../PRODUCT.md`](../PRODUCT.md), [`../THREAT-MODEL.md`](../THREAT-MODEL.md), [`../PROOF-STATUS.md`](../PROOF-STATUS.md), and [`../ROADMAP.md`](../ROADMAP.md) for product, boundaries, evidence, and planned work.
6. [`../releases/README.md`](../releases/README.md) and the exact cited release receipt when publication state matters.

## Ownership and references

Every independent product/repository owns its own current state, next step, and continuation checkpoint. A pointer to another project's brain is not permission to copy its status, history, or entire context into this one. Cross-project references must identify the project/repository, exact path or evidence locator, and why that specific fact is needed. Retrieve only the declared relevant evidence.

The private USB Website Platform repository is an evidence dependency only for BAH integration claims that explicitly cite USB, DFW Metro, or FreeVibeApps work in `PROOF-STATUS.md`. Its Project Brain is not part of BAH's default context. Other BAH work must not read or update USB's Project Brain.

The public repository contains public-safe BAH information only. Never add credentials, private owner records, or the implementation/specification of proprietary HITL Removal or Danger Mode add-ons. Their public names-only teaser is not an instruction to reconstruct them.

## Authority

This brain records project state; it does not authorize a Netlify publication, provider action, spending, database change, or other external effect. BAH website publication still requires a separate exact owner GO. Product proof and deployment receipts document evidence, not authority.
