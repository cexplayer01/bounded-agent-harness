# Contributing

Bug reports, reproducible compatibility findings, focused design feedback, and documentation corrections are welcome.

Code contributions are temporarily closed while contributor and relicensing terms are established. Please do not submit substantive pull requests yet. This protects contributors and preserves the ability to offer both the AGPL community edition and a commercial license without ambiguous ownership.

When reporting a problem:

1. state the command or API used;
2. include the smallest non-secret input that reproduces it;
3. include the observed error or contract code;
4. state the expected behavior; and
5. remove credentials, customer data, and proprietary prompts.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
